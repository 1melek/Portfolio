# Démos des projets

Déposer ici une courte vidéo (20 à 40 s, sans son, format MP4, moins de 8 Mo) avec exactement ce nom :

| Projet | Fichier vidéo | Image d'aperçu (optionnelle) |
|---|---|---|
| Agentic RAG Assistant | `rag.mp4` | `rag.jpg` |
| Quoi de neuf Docteur (chatbot) | `chatbot.mp4` | `chatbot.jpg` |
| THE ROOM | `theroom.mp4` | `theroom.jpg` |
| STUDAR | `studar.mp4` | `studar.jpg` |

Dès qu'un fichier est présent, il remplace automatiquement le schéma du projet sur le site.
Tant qu'il n'y a pas de vidéo, le schéma d'architecture animé reste affiché.
